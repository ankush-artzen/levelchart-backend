# ✅ Shopify Frontend & Backend App Setup

## Frontend (Next.js + Prisma + MongoDB)
- Set up Shopify app frontend using **Next.js**.
- Integrated **Prisma** ORM with **MongoDB** as the database.
- Connected frontend with backend APIs to handle store data.

## Backend (Level Chart Core Logic)
- Established backend architecture for the **Level Chart** app.
- Integrated with **Shopify** to handle store authentication and data syncing.
- Implemented **cron jobs** to:
  - Sync **product data**.
  - Sync **order data**.
- Synced data is successfully stored in **MongoDB**.

## Logging & Monitoring
- Integrated **Winston** logger for capturing application logs.
- Error logs are recorded for easier debugging and monitoring.

## API Development
- Created API endpoint to **save store data** to the database.
